# BDSLauncher — Agent Guide

Linux Minecraft Bedrock Dedicated Server launcher (Java 21 CLI).

## Build & Run

```bash
export JAVA_HOME=.tools/jdk-21.0.4
export PATH="$JAVA_HOME/bin:.tools/apache-maven-3.9.6/bin:$PATH"
mvn clean package -q
cp target/BDSLauncher-1.0.0.jar BDSLauncher.jar
java -jar BDSLauncher.jar
```

- **Must run from project root** — all paths are relative (`data/`, `.tools/`).
- No CLI args. Config only via `data/install.json`.
- No tests, no linters, no CI, no formatters, no git history.
- Fat JAR via `maven-shade-plugin` 3.5.3; main class `me.ngcsonsplash.bdslauncher.Main`.
- JAR in root is a manual copy from `target/` (not generated by `package`).

## Flow

`Main.main()` → environment check → load config → Tailscale setup → MCXbox download → BDS interactive install (if missing) → update check → **WorldPackManager** (pack sync) → shutdown hook → start MCXbox (silent, log to file) → start BDS (blocks via `waitFor()`).

## Architecture

| Package | Key classes |
|---|---|
| `me.ngcsonsplash.bdslauncher` | `Main.java` — orchestrator, shutdown hook |
| `.model` | `InstallState.java` (+ inner: `BdsInfo`, `McxboxInfo`, `TailscaleConfig`, `CleanupConfig`), `BdsMetadata.java`, `VersionRegistry.java` — JSON POJOs |
| `.service` | `EnvironmentCheck`, `InstallStateManager`, `BdsMetadataFetcher`, `BdsDownloadManager`, `McxboxBroadcastManager`, `UpdateManager`, `WorldPackManager`, `ConsoleInputManager`, `ProcessManager`, `TailscaleManager` |
| `.util` | `Printer.java` — all console I/O and user input (static) |

## Execution Quirks

- **BDS process:** stdout/stderr inherited, stdin via `ConsoleInputManager` (reads `System.in`, pipes to BDS). Launcher blocks on `waitFor()`.
- **MCXboxBroadcast:** stdin from `/dev/null`, stdout+stderr to `data/logs/mcxboxbroadcast.log`. No console output. Config option `cleanup.deleteMCXboxBroadcastLog` (default true) deletes log after stop.
- **Shutdown order:** BDS gets graceful `stop` + 30s wait, then `destroyForcibly()`. MCXbox and tailscaled get `destroyForcibly()` immediately. MCXbox log deleted after process stop if config enabled.
- **World pack sync:** Before MCXbox/BDS start, scans `worlds/<level-name>/behavior_packs/` and `resource_packs/` for `manifest.json`. Validates UUID, version. Generates `world_behavior_packs.json` / `world_resource_packs.json`. Logs skipped packs with reason.
- **ConsoleInputManager:** Virtual thread reads `System.in`, writes to BDS stdin pipe via `Process.getOutputStream()`. Synchronized writes — conflicts with `ProcessManager.sendCommand()` are safe.
- **Tailscale daemon:** Extracted from upstream tarball, stdout+stderr to `data/logs/tailscaled.log`. Socket at `data/tailscale/tailscale.sock`.
- **BDS download:** Uses `EndstoneMC/bedrock-server-data` (third-party GitHub raw JSON), not Mojang API. Interactive version selection prompt on first install.
- **No launcher self-update** — only BDS and MCXboxBroadcast are updated.

## External Dependencies

| Resource | URL |
|---|---|
| BDS version metadata | `raw.githubusercontent.com/EndstoneMC/bedrock-server-data/v2/versions.json` |
| MCXboxBroadcast JAR | `api.github.com/repos/MCXboxBroadcast/Broadcaster/releases/latest` (prefers `MCXboxBroadcastStandalone.jar`) |
| Tailscale tarball | `pkgs.tailscale.com/stable/tailscale_${version}_amd64.tgz` |

| `tailscale` | `enabled`, `version`, `authKey`, `userspace` |
| `cleanup` | `deleteMCXboxBroadcastLog` (default true) |
| top-level | `launcherVersion`, `autoUpdate`, `lastUpdateCheck` |
